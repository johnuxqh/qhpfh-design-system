# QHPFH Design System

Static design system bible for the **Queensland Patient Flow Hub (QHPFH)**.

## Purpose
This repository documents the initial design foundations used to guide future UI implementation in the `qhpf-prototype` repository. It focuses on clinical clarity, consistency, and accessibility.

## Contents
The page includes:
1. Overview
2. Design principles
3. Design tokens
4. Colour system
5. Typography
6. Spacing and layout
7. Header and navigation
8. Buttons
9. Cards and tiles
10. Filters and dropdowns
11. Slideout panels
12. Light and dark mode
13. Accessibility guidance
14. Component usage notes
15. Changelog/version notes

## Tech constraints
- Static site only.
- Plain HTML, CSS and vanilla JavaScript.
- No frameworks.
- No real patient data.

## Local preview
Open `index.html` directly in a browser, or run a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
