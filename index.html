1. Overview

This site is the first serious design system bible for the Queensland Patient Flow Hub (QPHFH). It sets a clinical, calm and practical baseline for future implementation work in the qhpf-prototype repository. All examples use placeholder content only and no patient data.

2. Design principles

  • Clinical clarity: Make critical information instantly scannable.
  • Operational speed: Reduce cognitive load for shift-based users.
  • Consistency: Use repeatable patterns and tokens across pages.
  • Accessibility first: Keyboard, contrast and readable structure are non-negotiable.

6. Spacing and layout

The content shell uses a max-width of 1680px and comfortable gutters. Core cards and modules are built on an 8px spacing rhythm.

Example module with spacing token use: padding var(--space-5), gap var(--space-3).

12. Light and dark mode

Theme tokens are defined using CSS variables under :root and [data-theme="dark"]. Both modes prioritise contrast and reduced eye strain in long clinical sessions.

13. Accessibility guidance

  • Maintain colour contrast at WCAG AA minimum.
  • Ensure all interactive controls are keyboard reachable.
  • Use semantic HTML headings and landmarks.
  • Never encode status by colour alone.

14. Component usage notes

Buttons trigger actions; cards summarise; filters refine datasets; slideouts reveal secondary context. Prefer one primary action per region to reduce mistakes under time pressure.
