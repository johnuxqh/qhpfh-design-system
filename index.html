Queensland Health · Patient Flow Hub

Design System v2.1

A hub-aligned design system for the prototype: sticky QH-style header, primary and secondary navigation, cool-light clinical UI tokens, dark mode mapping, universal list/grid patterns, slideouts, overlays, filters, buttons and status rules.

01 · Foundation

Design Principles

Use a flat, compact, blue-led clinical style. White surfaces hold data. Blue communicates active state and structure. Status colours communicate operational meaning only.

Clinical calm
Minimal decoration, restrained shadows and clear section rules. The interface should support scanning, not visual drama.
Navigation-first hierarchy
Header, primary menu and secondary menu mirror the Hub structure and remain sticky so readers can scroll or anchor-jump.
Token-led consistency
Ignore small AI colour drift. Use this system for all generated views unless a new clinical state is explicitly required.
